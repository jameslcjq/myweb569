适用版本：**食常财务1.2.34**。更新日期：**2026年10月22日**。

历史账查询用于把旧财务软件的账务资料保存到食常财务中，方便以后查账。它与当前正式账隔离，不回填现账期初，不参与当前账套的凭证生成、月结、财务报表或教育局上报。

## 一、旧软件需要导出哪些表

每家单位分别整理，不要把不同单位的期初和凭证混在一起。

| 资料 | 是否导入 | 导出要求 |
| --- | --- | --- |
| 科目余额表／科目期初表 | 必须 | 包含科目编码、科目名称、起始月份月初的借方余额和贷方余额；列出所有凭证会用到的科目，零余额科目也要保留 |
| 凭证管理／凭证分录明细表 | 必须 | 导出所选期间全部凭证的全部分录，含结转凭证；包含月份或日期、完整凭证字号、摘要、科目编码、借方金额和贷方金额，建议同时保留科目名称 |
| 总账 | 不导入，建议留存 | 用来核对各月期初、本月借贷发生额和期末余额 |
| 明细账 | 不导入，建议留存 | 用来核对凭证、摘要、金额及逐笔余额；旧软件按资产、负债、净资产、收入、支出分开导出的明细账也属于核对资料 |

**只有总账或明细账，不足以代替完整凭证导入。** 软件根据科目期初与凭证生成历史总账、明细账，不是直接展示旧账报表文件。

### 期初和期间怎样选

例如，现账启用月份为 **2026年1月**，需要查旧软件 **2023年1月至2025年12月** 的账：

- 期初月份填 **2023-01**；期初金额必须是 **2023年1月月初余额**。
- 结束月份填 **2025-12**。
- 凭证必须覆盖 **2023-01至2025-12** 的完整期间，包括各期结转凭证。

不要把2025年末余额当成2023年初余额。导出科目余额表时，先确认报表期间和“期初余额”列的含义；不能拿本期发生额、期末余额替代期初。历史账结束月份必须早于当前学校的现账启用月份，不要为了导入而随意修改现账启用月份。

### 导出文件整理要求

1. 支持 `.xls`、`.xlsx`，单个文件不超过20MB。保留旧软件原始文件，整理时使用副本。
2. 凭证按旧账原顺序导出，不要另行按日期、金额或科目排序。同月内查询保留导入行顺序，改变顺序会改变逐笔余额的展示过程。
3. 科目编码应保持文本格式，保留前导零；期初和凭证要使用同一套旧账科目编码，不必改成食常财务现账科目。
4. 期初表需含全部凭证科目，不能只导出有余额的科目。若包含上级汇总科目，其余额须等于下级明细合计；凭证应落在实际记账的末级科目。
5. 已兼容标准模板、已回测的多层科目余额表，以及科目编码和名称合列的凭证表；不能保证所有旧软件格式直接识别。
6. 格式无法识别时，点击“下载导入模板”，按模板整理副本。模板含“期初科目”“凭证”两个工作表，**请替换全部示例数据**。可以在两个文件选择框中选择同一个工作簿，再分别指定对应工作表。

需要分年度或分期间导入时，每册都要有自己的起始月月初余额及该册完整凭证，不能只拆凭证而沿用错误的期初。不同账册不会自动拼接为一个连续账册。

## 二、怎样导入并保存

1. 先确认当前学校／账套正确，且已设置现账启用月份。进入“设置 → 数据管理”，先点击“立即备份”。
2. 打开侧栏“历史账查询”，点击“导入历史账”。
3. 填写“账册名称”，建议用“单位名称＋期间”，例如“某学校2023—2025年旧账”。
4. 选择“期初月份”和“结束月份”。
5. 在“科目期初文件”中选择余额表或期初表，并选中实际存放数据的工作表。
6. 在“凭证文件”中选择完整凭证表，并选中对应工作表。
7. 点击“校验并导入”，检查预览显示的科目数、分录数。**分录数是凭证里的行数，不是凭证张数。**
8. 如果出现同编码、不同名称的提示，逐条对照原账。确认确属同一科目后，勾选“已核对名称差异，按相同科目编码查询并保留原文”。有疑问就取消，先检查文件；不要为通过校验而直接确认。
9. 点击“确认保存历史账”。看到成功提示、账册出现在选择列表中后，才表示保存完成；只选文件或通过预览不等于保存。

名称差异确认后，查询按科目编码归集，原始名称和摘要保留。账册顶部可以点击“查看核对记录”。

**每次导入都会新增一册，不覆盖已有账册，也不自动合并或去重。** 不要因刷新页面或重新启动软件而重复导入。

### 常见校验提示如何处理

| 提示或现象 | 应检查什么 |
| --- | --- |
| 未识别到完整表头 | 检查选中的工作表是否正确；必要时按模板整理，不能只改文件后缀 |
| 科目不在期初表中 | 补齐对应科目，包括期初为零的科目；核对编码是否丢失前导零 |
| 上级期初与下级合计不一致 | 检查是否漏了明细科目，或误用了本期、期末金额 |
| 期初借贷不平 | 对照旧账完整期初；不要人为加一笔数来凑平 |
| 某张凭证借贷不平 | 检查是否漏了分录、只导出某个科目，或漏了部分凭证内容 |
| 凭证月份超出账册范围 | 核对文件期间及所填起止月份，排除混入其他期间的凭证 |
| 历史账须结束于现账启用月份之前 | 核对是否把当前正式账期间也导了进来 |

校验通过不代表系统能识别所有漏单：例如整张借贷平衡的凭证被遗漏，仍可能通过校验。因此保存后还要与旧总账、明细账核对。

## 三、怎样查询总账、明细账和凭证

1. 在“历史账查询”顶部选择已保存的历史账册。
2. 选择“历史科目”、起始月份和结束月份，点击“查询”。查询范围须在该账册期间之内。
3. “总账”按月显示期初余额、本月借方、本月贷方、期末余额。双击某个月，会切换到该月的明细账。
4. “明细账”显示日期、凭证字号、摘要、科目、原始科目名称、借贷金额和逐笔余额。双击一行，可查看对应月份、凭证字号的整张凭证分录。
5. “期初科目”页签显示该账册导入的原始科目期初；它不是任意所选查询月份的月初数。当前查询期间的期初、期末见查询结果顶部。

余额采用**借方为正、贷方为负**的显示方式。例如余额 `-500.00` 表示贷方余额500元，不能仅凭负号判断错误。

查询上级科目时会汇总下级明细。总账月份双击后，查询范围会变成那一个月；如需再次查询全期间，请重新选择起止月份并点击“查询”。更改科目或期间后，也需重新查询再导出。

### 导出Excel和核对

点击“导出查询结果”，会生成一个含“总账”“明细账”两个工作表的Excel文件。导出范围是**当前已查询的一个科目和期间**，不是整册所有科目。

首次导入建议这样核对：

- 对照旧总账，核对银行存款等关键科目各月的期初、借贷发生额、期末余额。
- 对照旧明细账，核对摘要、凭证字号、金额、逐笔余额及原账顺序。
- 确认结转凭证没有漏导；异常科目名称的原文仍在。

确认一致后，再做一次完整备份。已保存的历史账不依赖原Excel文件才能查询，但原始文件仍应留存，便于日后核对或重新导入。

## 四、导错或重复导入怎么办

选中需要移除的账册，点击“撤回本账册导入”，核对确认框后撤回。

这会删除**选中的整册历史查询数据**，不会删除正式账。当前没有在历史查询页逐条修改凭证的流程；应在导入文件副本中修正，重新校验导入。撤回前先保留原文件或备份，并仔细确认选中的是哪一册。

不要为了删掉一册重复导入的历史账而恢复整库旧备份，否则正式账也会回退。

## 五、怎样备份和恢复

### 做一份包含历史账的备份

1. 进入“设置 → 数据管理 → 完整数据备份”。
2. 点击“立即备份”，等待“备份成功”，并确认备份列表出现新文件。
3. 点击“打开目录”，把生成的 `.zip` 文件再复制到另一块磁盘或可靠的备份位置。不要只保留在同一块硬盘。
4. 可开启“自动备份”，选择每次启动、每天或每周，并设置保留份数。日常仍应检查备份是否实际生成；导入核对完成后建议手动备份一次。

历史账与正式账保存在同一本地数据库中，手动、自动备份都会包含已保存的历史账，不需要单独勾选历史账。自动备份由软件运行时执行，软件关闭期间不会自行产生备份。放在其他目录中的旧软件原始Excel文件，请另外保管。

### 从备份恢复

**恢复是整体回到备份时点，不是把历史账追加到现在的正式账。** 同一本地数据库中的正式账、历史账都会回退，备份之后新增或修改的数据不会保留。

1. 先停止录入，保全当前数据，并核对目标备份的日期和来源。
2. 在“设置 → 数据管理”中，点击备份列表的“恢复”，或使用“选择备份恢复”选择备份文件。“导入备份文件”只是把文件加入备份列表，不等于已经恢复。
3. 阅读确认提示，确认需要整库恢复后再执行。
4. 等待“恢复完成”，按提示确认，页面会刷新加载恢复后的数据。
5. 重新选择正确学校和历史账册，检查历史科目、期间、总账和明细账，并检查正式账余额、凭证及结账状态。

恢复前软件会尝试创建安全快照，但仍应自行保留重要备份。如果选用的是导入历史账之前的备份，恢复后就不会有那批历史账，需要重新导入。

**若只是想补回历史账，同时保留当前正式账，应使用原始期初和凭证文件重新导入历史账，不要用旧备份覆盖当前库。**

本版本已使用两家历史账副本验证手动备份、自动备份及恢复；恢复后的总账、明细账查询结果和正式账测试记录均与备份时一致。实际操作仍应选择正确的备份时点。
